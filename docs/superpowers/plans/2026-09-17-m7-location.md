# Loreframe M7 — Location Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Location page that composes reusable Loreframe components — hero, info block, Foundry-linked lists
(Points of Interest, Notable NPCs, Factions), map, rumours, GM secrets and an embedded Gallery block (spec §21, §51 M7).

**Architecture:**
- *Foundry links* stay native: Foundry stores links as the text `@UUID[uuid]{label}` and enriches them on display
  (`common/prosemirror/content-link-plugin.mjs` inserts exactly that text on drop). A new `links` field type holds
  `{uuid, label, note}` items rendered as `ul > li > p(link) + p(note)` and read back by parsing that text.
  Labels lose `[]{}`, invalid uuids degrade to plain labels. The inspector accepts documents dragged from the sidebar.
- *Composition*: renderers receive `embed(templateId, {key, values, preset})`, which renders another registered
  template as a nested block (own root attributes, instance id `<parent>-<key>`, secret wrapper when GM-only). The
  Location puts a Gallery block into its `gallery` slot; the nested block keeps its own toolbar and inspector.
- *Optional regions*: only regions stored in the document (rich text and slots: summary, map, rumours, secrets,
  gallery) are toggleable. Property lists and info rows disappear when empty, so no toggle can lose data.
  "Written" detection compares a region structurally with a fresh render (ignoring Foundry secret ids) and counts
  text, images and nested blocks as content.
- *Inspector lists*: the single image list becomes a list of lists (`images` | `links`) addressed by field id.

**Spec:** §2.1, §19, §21, §22, §24, §51 M7.

## Tasks (each: failing tests → implement → `npm run check`)

1. **Links**: `LinkItem`, `links` field type, validation, `formatLink`/`parseLink`.
2. **Composition**: `TemplateRenderer.renderTree`, `RenderContext.embed` (derived ids, secret wrapper, depth guard).
3. **Block document**: read `links`; `writtenRegions` for rich text and slots (structural, secret ids ignored).
4. **Location template**: hero, kind/region meta, summary, info rows (right/left/full), description, map region,
   POI / NPC / faction link lists, rumours, nested GM secret, gallery slot with an embedded Gallery; presets
   editorial/minimal/arcane; styles; EN/RU copy.
5. **Inspector**: lists of images and links, per-list add/remove/move, drop documents onto a link list.
6. **Live verification**: insert, drop Scene/Journal/Actor links, view-mode enrichment and navigation, gallery
   nested inspector, toggles with confirmation, secrets, save/reload, narrow width, both themes, console.
