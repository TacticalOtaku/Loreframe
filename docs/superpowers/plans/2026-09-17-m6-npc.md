# Loreframe M6 — NPC Templates, Presets & Optional Sections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** NPC Compact Card and NPC Dossier render as showcase-quality structures with several visual presets, optional
sections toggled from the inspector, and a style section (preset, portrait position, density) (spec §8, §20, §24, §51 M6).

**Architecture:**
- *Presets*: the first built-in presets (`editorial`, `minimal`, `arcane`, `bestiary`) are registered by `registerBuiltIns`.
  A preset is only a root class (`loreframe-preset--<id>`) plus optional default values; the same NPC structure renders
  with any of them. The inspector's Style section and the library preview both offer the preset; `updateBlock` and
  `insert` accept a preset.
- *Inspector groups*: fields may declare `inspectorGroup` (`general` | `sections` | `style`); defaults stay as in M5
  (text/image → General, select/boolean → Options). The Style section also carries the preset select (form key `_preset`).
- *Optional sections*: boolean `show-<section>` fields. A disabled section is not rendered. Disabling a section whose
  text differs from its placeholder asks for confirmation (the text is removed; Ctrl+Z restores it).
- *Empty text fields*: a text field whose element is absent reads as `""` (renderers omit empty optional text), so a
  cleared value no longer falls back to its placeholder on the next inspector edit (also fixes Hero Image captions).
- *GM Secrets*: rendered as a nested bare Foundry secret (`TreeElement.secret`) inside a rich-text field, so
  `enrichHTML` strips it for players and the reveal toggle works. NPC sections use `div`, never `section`, because the
  reveal regex (`<section[^i]+id="…"`) must not start at another `<section>`.

**Spec:** §8, §20, §22, §24, §28–§31, §51 M6, §53 (content checks).

5. **Styles**: NPC layout (flex-wrap portrait/text, section grid), four presets, long names, tall/no portrait,
   narrow widths, both themes, reduced motion (no motion used).
6. **Live verification**: insert both NPCs, switch presets and portrait positions, toggle sections (with confirmation),
