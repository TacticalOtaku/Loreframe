# Loreframe

**Переиспользуемые визуальные блоки, адаптивные макеты и RPG-шаблоны контента для редактора журналов Foundry VTT 14**

Расширяет встроенный редактор ProseMirror в Foundry выпадающим меню **Loreframe** и **библиотекой шаблонов** с поиском — каждый блок сохраняется как чистый семантический HTML прямо внутри страницы журнала.

## Установка

Вставьте **URL манифеста** в окно установки модулей Foundry VTT (**Дополнительные модули → Установить модуль → Manifest URL**):

```text
https://github.com/TacticalOtaku/Loreframe/releases/latest/download/module.json
```

**Требования:** Foundry VTT **14** (проверено на `14.367`), не зависит от игровой системы (интеграция перетаскивания актёров `dnd5e` **5.3.3** включается автоматически при наличии системы и настраивается в параметрах мира).  
**Ручная установка:** скачайте `loreframe-v<версия>.zip` со страницы [GitHub Releases](https://github.com/TacticalOtaku/Loreframe/releases/latest), распакуйте в `Data/modules/loreframe` и включите **Loreframe** в управлении модулями мира.

## Обзор

Loreframe расширяет стандартный редактор журналов ProseMirror в **Foundry VTT 14**, не заменяя его. Вы продолжаете писать форматированный текст и использовать нативные ссылки Foundry, а ваши заметки остаются чистыми и читаемыми, даже если модуль Loreframe будет отключён.

- **Чистый HTML:** блоки хранят структуру в атрибутах `data-loreframe-*` внутри стандартных тегов (`aside`, `section`, `div`, заголовков, абзацев) — без проприетарного формата страниц и привязки к модулю.
- **Правка прямо на странице:** текст и вложенный контент редактируются непосредственно в ProseMirror с полной поддержкой отмены и повтора (`Ctrl+Z`). Пересборка блока в инспекторе сохраняет написанный текст и содержимое вложенных слотов.
- **Встроенные стили и поддержка тем:** оформление адаптируется под светлую и тёмную темы Foundry (`.theme-light` / `.theme-dark`) и включает четыре визуальных стиля: **Editorial**, **Minimal**, **Arcane** и **Bestiary**.
- **Безопасные секреты мастера:** приватные заметки и секции секретов мастера компилируются в стандартные блоки Foundry `<section class="secret">`, скрытые от игроков до раскрытия.
- **Карточки актёров `dnd5e` перетаскиванием:** при перетаскивании актёра на страницу журнала можно вставить обычную ссылку Foundry либо готовый снимок **Карточка НИП** / **Досье НИП**.

## Встроенная библиотека

Loreframe поставляется с **29 встроенными шаблонами** и **4 визуальными стилями** (`Editorial`, `Minimal`, `Arcane`, `Bestiary`) и автоматически исключается из редакторов чата, чтобы инструменты появлялись только на страницах журналов.

| Категория               | Шаблоны                                                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Блоки и врезки**      | Заголовок, Подзаголовок, Разделитель, Цитата, Текст вслух, Заметка, Предупреждение, Предание, Заметка ГМ, Секрет                      |
| **Медиа и данные**      | Картинка + текст, Главная иллюстрация, Список ключ/значение, Теги, Строка характеристик                                               |
| **Галереи**             | Галерея _(режимы: ровная сетка, портрет, альбомная, главное фото + сетка и с подписями)_                                              |
| **Макеты**              | Две колонки, Колонки 33/66, Колонки 66/33, Три колонки, Боковая панель слева, Боковая панель справа, Обложка + текст, Сетка карточек  |
| **Персонажи**           | Карточка НИП, Досье НИП _(стили: Editorial, Minimal, Arcane, Bestiary)_                                                               |
| **Локации и лор**       | Локация, Статья вики _(с автоматически формируемым оглавлением и гибким инфобоксом)_                                                  |

## Работа с Loreframe

### Вставка блоков

1. Откройте текстовую страницу журнала в режиме **редактирования** и поставьте курсор в нужное место.
2. Выберите шаблон в меню **Loreframe** на панели инструментов (**Избранное**, **Недавние**, **Быстрые блоки**, **Макеты**, **Структуры**) или нажмите **Открыть библиотеку шаблонов…** для поиска, выбора категорий, переключения стилей и живого предпросмотра перед вставкой.
3. Фокус автоматически переходит в основное поле блока, чтобы вы могли сразу печатать.

> [!TIP]
> **Вложенность:** блоки можно вкладывать внутрь контейнеров-макетов (колонок, сеток карточек, слотов обложки с текстом или области галереи в шаблоне «Локация»). При вставке из любого другого места новый блок аккуратно добавляется после текущего.

### Редактирование блоков и навигация с клавиатуры

Клик внутри любого блока открывает компактную плавающую панель с действиями **Изменить**, **Дублировать** и **Удалить**.

| Действие              | Поведение                                                                                                                                                                     |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Фокус панели**      | <kbd>Alt</kbd>+<kbd>F10</kbd> переводит фокус на панель блока; <kbd>←</kbd> / <kbd>→</kbd>, <kbd>Home</kbd>, <kbd>End</kbd> переключают кнопки; <kbd>Esc</kbd> возвращает на страницу |
| **Изменить**          | Открывает **инспектор блока** для правки заголовков, изображений и alt-текста, порядка галереи, ссылок Foundry, опциональных секций и стилей                                 |
| **Дублировать**       | Клонирует блок с новым идентификатором экземпляра (вставленные и перетащенные блоки также получают уникальные ID)                                                            |
| **Удалить**           | Запрашивает подтверждение для макетов, структур и блоков с вашим текстом (<kbd>Ctrl</kbd>+<kbd>Z</kbd> отменяет удаление)                                                     |

- **Сохранность форматирования:** все текстовые поля и вложенные слоты редактируются прямо в ProseMirror. Повторное применение настроек в инспекторе переносит существующий форматированный текст и вложенные блоки без потерь.
- **Переключение секций:** скрытие необязательной секции, в которой уже есть ваш текст, сначала просит подтверждения; отмена оставляет инспектор открытым и текст нетронутым.
- **Защита версий:** блоки, чья версия отличается от зарегистрированного шаблона, а также неизвестные шаблоны остаются в режиме «только чтение» и никогда не перезаписываются.

### Мои шаблоны

Превратите любой настроенный блок в личный пресет, доступный во всех мирах:

- В окне **Шаблоны** выберите **Сохранить как свой шаблон** на любом шаблоне.
- В **инспекторе блока** выберите **Сохранить как шаблон…**, чтобы зафиксировать выбранный стиль, секции и параметры.

Сохранённые варианты привязаны к вашему **пользователю** Foundry (до 100 шаблонов); их можно редактировать, дублировать, удалять, экспортировать и импортировать в формате JSON (до `256 000` символов с полной поддержкой Unicode и кириллицы):

- Вставленные в журнал блоки остаются обычными блоками базового шаблона — удаление пользовательского шаблона убирает его только из **Избранного** и **Недавнего**, не затрагивая страницы журналов.
- Варианты, чей базовый шаблон или стиль временно недоступен, бережно сохраняются до повторного включения базы.

### Секреты ГМ, ссылки Foundry и оглавление вики

- **Контент только для ГМ:** секции _Заметка ГМ_, _Секрет_ и _Секреты ГМ_ оборачиваются в стандартные блоки секретов Foundry (`<section class="secret">`) и остаются скрытыми от игроков до раскрытия.
- **Визуальное скрытие против секретов:** установка инфобокса статьи вики в режим _Скрыто от читателей_ прячет блок только визуально средствами CSS вне редактора — никогда не используйте его для конфиденциальных заметок мастера.
- **Ссылки Foundry:** списки вроде _Интересных мест_, _Важных НИП_, _Фракций_ и _Связанных записей_ хранят стандартные ссылки `@UUID[uuid]{label}`. Перетащите любую сцену, актёра, предмет или страницу журнала с боковой панели прямо в область сброса в инспекторе.
- **Оглавление вики:** блок _Оглавление_ в шаблоне **Статья вики** автоматически строится по заголовкам статьи в режиме просмотра, поэтому ссылки всегда актуальны.

### Снимки актёров `dnd5e`

Когда активна система **dnd5e**, перетаскивание актёра (при правах не ниже **Наблюдатель**) на страницу журнала предлагает выбрать вариант вставки:

- **Стандартная ссылка Foundry**
- **Карточка НИП**
- **Досье НИП**

> [!IMPORTANT]
> Импортированные карточки являются **снимками** — последующие правки актёра не изменяют текст журнала. Публичная биография попадает в краткое описание, а приватные/ГМ-заметки переносятся строго в блок **Секреты ГМ** внутри досье. Переключить обработку перетаскивания из системы можно в настройке мира **Интеграции с игровыми системами**.

## Разработчикам модулей

Loreframe предоставляет замороженный API расширения по пути `game.modules.get("loreframe").api` начиная с хука `loreframeRegisterTemplates` (вызывается на этапе `setup`), за которым следует `loreframeReady` на этапе `ready`.

<details>
<summary><strong>Пример: регистрация собственного стиля и декларативного шаблона</strong></summary>

```js
Hooks.once("loreframeRegisterTemplates", (api) => {
  api.registerPreset({ id: "grim", name: "MYMOD.Preset.Grim" });

  api.registerTemplate({
    id: "mymod-rumour",
    version: 1,
    name: "MYMOD.Template.Rumour",
    category: "campaign",
    type: "block",
    renderer: "callout",
    rendererOptions: { tone: "lore" },
    presets: ["grim"],
    fields: [{ id: "title", type: "text", label: "MYMOD.Field.Title", default: "Слух" }],
  });
});
```

</details>

### Публичный API

| Элемент                                                   | Описание                                                                                                    |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `version`                                                 | Строка текущей версии модуля Loreframe                                                                      |
| `openTemplateLibrary()`                                   | Открывает окно библиотеки шаблонов                                                                          |
| `insertTemplate(id, { preset }?)`                         | Вставляет шаблон в последний активный редактор; возвращает `false`, если активного редактора нет            |
| `registerTemplate(definition)` / `unregisterTemplate(id)` | Регистрирует или удаляет декларативный шаблон (`LoreframeTemplateDefinition`)                               |
| `registerPreset(preset)`                                  | Регистрирует визуальный стиль (добавляет класс `loreframe-preset--<id>` к корню блока)                     |
| `registerSystemAdapter(adapter)`                          | Регистрирует адаптер игровой системы (см. [`src/integrations/types.ts`](src/integrations/types.ts))         |

### Правила шаблонов и разметки

Шаблоны описываются исключительно **декларативными данными** — сторонние модули не могут регистрировать исполняемый код рендера через публичный API. Каждое дерево проходит через `serializeTree` (жёсткий белый список тегов и атрибутов, экранирование HTML и безопасная фильтрация URL).

<details>
<summary><strong>Встроенные рендеры (17) и хранимые DOM-атрибуты</strong></summary>

**Встроенные рендеры:**

- Текст и врезки: `heading`, `subtitle`, `divider`, `quote`, `callout` (`rendererOptions.tone`: `note`, `lore`, `warning`, `read-aloud`, `gm-note`, `secret`)
- Медиа и данные: `media`, `hero-image`, `key-value`, `tags`, `stats-row`, `gallery`
- Макеты: `columns` (`rendererOptions.pattern`: `halves`, `narrow-wide`, `wide-narrow`, `thirds`, `sidebar-left`, `sidebar-right`), `hero-content`, `card-grid`
- Структуры: `npc` (`rendererOptions.variant`: `card`, `dossier`), `location`, `wiki-article`

**Контракт хранимого HTML:**

- Корни блоков несут атрибуты `data-loreframe-template`, `data-loreframe-version` и `data-loreframe-instance`, а также опциональные `data-loreframe-preset` и `data-loreframe-opt-<field>`.
- Семантика хранится строго в `data-loreframe-*`; CSS-классы (`.loreframe*`) отвечают только за оформление.
- Блоки с неизвестным ID шаблона или несовпадающим `data-loreframe-version` не изменяются и остаются в режиме «только чтение» для Loreframe.

</details>

## Разработка

Требуется **Node.js `>=24`**. GitHub Actions ([ci.yml](.github/workflows/ci.yml)) запускает `npm run check` и `npm run package` при пушах в `main`; релизы по тегам `v*` публикуют ZIP-архив и `module.json` через [release.yml](.github/workflows/release.yml).

```bash
npm install
npm run check    # TypeScript, ESLint, Stylelint, Vitest, production-сборка Vite
npm run format   # Форматирование репозитория с помощью Prettier
npm run deploy   # Копирование dist/module/ в FOUNDRY_DATA или %LOCALAPPDATA%/FoundryVTT/Data
npm run package  # Проверка module.json и упаковка dist/loreframe-v<версия>.zip
npm run release  # Запуск npm run check и сборка dist/loreframe-v<версия>.zip
```

## Использование ИИ (AI Disclosure)

При разработке использовались ИИ-инструменты как вспомогательный ассистент (черновики кода, рефакторинг, тесты, документация и переводы). Вся архитектура, код, логика работы, пользовательские тексты и русская/английская локализации проверены, протестированы и поддерживаются владельцем репозитория **TacticalOtaku**, который является единственным автором модуля.

Все включённые в пакет ресурсы и материалы соответствуют [политике Foundry VTT в отношении ИИ-контента](https://foundryvtt.com/article/ai-policy/) — модуль не содержит заранее сгенерированных ИИ-артов, аудио или лорного контента.
